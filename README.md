## 👋🏽 Introduction

Welcome to the repository of my personal portfolio website. This site showcases my skills, projects, and a bit about myself.

The project is built with a simple frontend stack and is structured to support clean development, maintainability, and future scalability.

## 🛠 Technologies used

- **HTML**
- **JavaScript**
- **Sass (SCSS)**
- **Vite**
- **Node.js & npm**
- **Prettier**
- **ESLint**
- **EditorConfig**

## 🚀 Getting started

### 1. Prerequisites

Make sure the following are installed on your machine:

- **Node.js**
- **npm**
- **Git**
- **VS Code** (recommended)

### 2. Clone the repository

```bash
git clone https://github.com/Chleih/Website-Chleih.git
```

### 3. Navigate to the project

```bash
cd Website-Chleih
```

### 4. Install dependencies

```bash
npm install
```

### 5. Start local development

```bash
npm run dev
```

## 📦 Available scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run lint:fix
```
